# AeroTense — Antigravity & Tensegrity Fine Craftsmanship 🛸

> **Struktura shakli — tortishish kuchi inkorida.**  
> Havoda muallaq turuvchi tensegrity konstruksiyalari va yog'och san'ati. Woodwrights (woodwrights.co.nz) premium minimalist uslubi va aerokosmik fizika simulyatsiyasiga asoslangan veb-sayt.

---

## 🌟 Asosiy Xususiyatlar (Key Features)

- **Interaktiv 3D Tensegrity Simulyatori (Three.js / WebGL):**
  - Foydalanuvchi 0 kg dan 150 kg gacha og'irlik qo'yib ko'rishi mumkin.
  - Markaziy kabel tarangligi ($F_c$), 4 ta burchak simlari kuchi va mikrometrik egilish real vaqtda hisoblanadi.
  - Modelni 360° burish, yaqinlashtirish, kuch vektorlarini yoqish/o'chirish va rentgen (wireframe) rejimi.
- **3D Hero Parallax Fon:**
  - Havoda qalqib turuvchi nozik simli va qora yong'oq daraxtli mebel modeli, kursorga ta'sirchan harakat va kosmik chang zarralari.
- **Bilingual (Ikki tilli):**
  - O'zbek tili (UZ) va Ingliz tili (EN) o'rtasida to'liq almashish.
- **Featured Spotlight (The Apex-01 Levitating Console):**
  - Haqiqiy vaqtda yog'och turi (Yong'oq, Oq eman, Dudlangan eman) va furnitura qotishmasi (Titan, Obsidian, Satin Jez) o'zgarishi, dinamik narx hisoblash.
- **Woodwrights Uslubidagi Materiallar Kutubxonasi:**
  - 6 xil premium material namunasi va $0 bepul Master Swatch Box buyurtma qilish tizimi.
- **Arxitektorlar & BIM Portali:**
  - 3D CAD/BIM (.STEP, .OBJ, .DWG, Revit) to'plami va maxsus arxitektura loyihalari so'rovi.

---

## 🛠 Texnologiyalar Steki (Tech Stack)

- **Frontend:** React 19 + TypeScript + Vite
- **3D / Grafika:** Three.js + WebGL
- **Styling:** Tailwind CSS + Lucide React
- **Animatsiyalar:** Framer Motion + Canvas Confetti

## 🚀 O'rnatish va Ishga Tushirish (Getting Started)

```bash
# Repozitoriyani klonlash
git clone https://github.com/akbarovhaydarali886-star/aerotense.git
cd aerotense

# Kerakli paketlarni o'rnatish
npm install

# Dev-serverni ishga tushirish
npm run dev

# Ishlab chiqarish uchun build olish
npm run build
```
